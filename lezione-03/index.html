Recap.

Le formule sono valide quando l'argomento indicato tende a zero; gli angoli sono misurati in radianti.

01

Logaritmo

Se an → 0, allora log(1+an) ∼ an.

Potenze

potenze e radici

Trigonometria

Se an → 0, seno, coseno e tangente forniscono tre nuovi equivalenti.

angoli in radianti

Teorema 4.62 · Epsilon 1

I tre limiti notevoli trigonometrici.

Il teorema è enunciato per x → 0; nelle successioni si usa con x = an → 0.

Forma per successioni

Se an ≠ 0 definitivamente e an → 0, allora:

gli angoli devono essere misurati in radianti.
